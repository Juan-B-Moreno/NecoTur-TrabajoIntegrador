La pagina web se encuentra hosteada en un servidor actualmente. La URL es juanm.com.ar
Si se quiere ejecutar en una computadora:

Para ejecutar el proyecto:

Necesario: 
Node.js (con los package del archivo package.json (server/pakage.json))
MySQL funcional con la base de datos (juanm_necotur.sql).
En .env cambiar la ubicacion de la base de datos, con las credenciales que se le de. 


Para ejecutar el backend se debe hacer:
cd "\Proyecto Integrador - Trabajo finalizado\server"
npm install
npm run dev

Para ejecutar el frontend se debe hacer: 
cd "\Proyecto Integrador - Trabajo finalizado\proyecto-migrado-react"
npm install
npm run dev

4 Instalación local

  1. Crear base MySQL (ej. necotur) e importar juanm_necotur.sql
  2. Copiar server/.env.example → server/.env y completar credenciales
  3. Ejecutar npm install dentro de server/
  4. Arrancar con npm run dev
  5. Abrir http://localhost:3000 (nunca el HTML directo desde disco)

Variables de entorno mínimas

PORT=3000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=tu_clave
DB_NAME=necotur
SESSION_SECRET=string_largo_y_aleatorio_min_32_chars
NODE_ENV=development
Verificación exitosa En consola debe aparecer: MySQL conectado: localhost/necotur

5 Despliegue en producción (WNPower)

  1. Subir server/ completo y ejecutar npm install en el servidor
  2. Subir public_html/ completa, incluida la carpeta js/
  3. Crear base en el panel e importar el SQL
  4. Configurar .env con credenciales del hosting (DB_NAME=usuario_necotur)
  5. Crear app Node.js apuntando a server/src/app.js
  6. Reiniciar la aplicación tras cada cambio
Error frecuente Subir HTML y CSS pero olvidar public_html/js/ → el sitio carga vacío aunque la API funcione.

Permisos de escritura

Node debe poder escribir en public_html/img/{tipo}/{id}/ al subir imágenes.

7 Checklist post-despliegue

  • /api/public/noticias?limit=3 devuelve JSON
  • /js/public-site.js devuelve JavaScript (no 404)
  • El index muestra tarjetas con contenido
  • Login redirige al panel correcto
  • Log muestra MySQL conectado: ...
  • HTTPS activo en el dominio
  • SESSION_SECRET único en producción

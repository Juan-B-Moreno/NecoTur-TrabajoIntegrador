# Necochea Turismo — Frontend React

Migración del sitio HTML a React (SPA).

## Desarrollo

```bash
# Terminal 1 — Backend
cd ../server
npm run dev

# Terminal 2 — Frontend React
npm run dev
```

Abrí http://localhost:5173

## Build producción

```bash
npm run build
```

Genera `dist/` para servir con Express (ver Fase 8 del plan).
